🚀 Welcome Back to CodeByTushu!

In today’s video, we solve LeetCode 66 — Plus One using Array & Math in Java.

We are given a large integer represented as an integer array of decimal digits, where each element represents a single digit from most significant to least significant. Our goal is to increment the large integer by one and return the resulting array of digits without leading zeros.

We iterate backwards from the least significant digit toward the most significant digit. If the current digit is less than 9, we simply increment it by 1 and immediately return the array. If the digit is 9, it rolls over to 0 and we continue leftward to propagate the carry. If all digits were 9, we allocate a new array of length n + 1 with the first digit set to 1, achieving optimal O(N) time and O(1) auxiliary space.

🔥 Problem Highlights

✅ Reverse traversal handles schoolbook decimal addition seamlessly
✅ In-place modification of digits avoids unnecessary reallocations
✅ Early return as soon as a non-9 digit absorbs the carry
✅ Handles all-nines overflow corner case like [9, 9, 9] to [1, 0, 0, 0]
✅ Clean single-pass carry propagation
✅ Time Complexity: O(N) | Auxiliary Space Complexity: O(1)

🚀 Welcome Back to CodeByTushu!

In today’s video, we solve LeetCode 1390 — Four Divisors using Math & Array in Java.

We are given an integer array nums and need to return the sum of divisors of integers in the array that have exactly four distinct positive integer divisors. If an integer does not have exactly four divisors, it contributes 0 to the sum.

For each number n in nums, we iterate potential divisors d from 1 up to floor(sqrt(n)). Each divisor d yields a paired divisor n / d. If d * d == n, it only contributes 1 divisor; otherwise it contributes 2. If at any point the divisor count exceeds 4, we prune early. ✅ Square numbers like 9 or 25 have an odd number of divisors and cannot have exactly four
✅ Numbers with 4 divisors are either p^3 or p * q for distinct primes p, q
✅ Zero auxiliary memory overhead using clean scalar counters
✅ Time Complexity: O(N * sqrt(M)) | Auxiliary Space Complexity: O(1)

🚀 Welcome Back to CodeByTushu!

In today’s video, we solve LeetCode 1975 — Maximum Matrix Sum using Greedy & Matrix in Java.

We are given an n x n integer matrix and can multiply any two adjacent cells by -1 any number of times. Our goal is to maximize the summation of all matrix elements.

Because any operation flips the signs of two adjacent cells simultaneously, the parity of the count of negative numbers remains strictly invariant. If the total number of negative values is even, we can flip all numbers to positive. If it is odd, exactly one negative sign must remain, and greedily placing that negative sign on the element with the minimum absolute value maximizes the total sum.

🔥 Problem Highlights

✅ Flipping signs of two adjacent cells preserves the parity of negative numbers
✅ Any negative sign can be propagated anywhere in the grid via a path of flips
✅ Even negative count allows making all matrix elements positive
✅ Odd negative count leaves exactly one negative element: the minimum absolute value
✅ Single pass computes absolute sum, negative count, and min absolute value
✅ Time Complexity: O(N^2) | Auxiliary Space Complexity: O(1)
